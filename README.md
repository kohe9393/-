# Script Flow

英文を貼るだけで、音声つきの音読教材になる学習アプリ。
[scriptflows.app](https://scriptflows.app/) の学習の仕組み（英文を入れる → 英日対訳・重要単語・パート分割の教材ができる →
音読しながら分からない箇所に印を付けると、その場で AI が解説する）を再現したものです。

## 学習の流れ

1. **貼る** — 英文スクリプトを貼り付けるか、教科書やプリントの写真をアップロードする（写真は Claude の画像入力で書き起こし）
2. **できる** — 文分割 → 英日対訳 → 重要単語の抽出 → パート分割 → レベル判定（共通テスト / 英検2級 / TOEIC / TOEFL）が自動で付く
3. **読む** — 文ごとに音声を再生して音読・シャドーイング。速さ、繰り返し回数、再生範囲（パート単位）、ループを調整できる
4. **印を付ける** — 分からない箇所をドラッグで選び、「聞き取れない / 単語 / 文法」のどれでつまずいたかを記録すると、その場で AI が解説する
5. **振り返る** — 単語帳（一覧・カード）と、教材をまたいだ弱点レポートでつまずきの傾向を見る

## 動かす

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を書く
npm run dev                  # http://localhost:3000
```

`ANTHROPIC_API_KEY` が無くても起動します。その場合サンプル教材と音読機能はそのまま使え、
貼り付けた英文は「対訳・語義なしの簡易教材」として取り込まれます（文分割・段落パート・頻出語の抽出までは動きます）。
対訳・重要単語・AI 解説・写真の読み取りにはキーが要ります。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 本番ビルド |
| `npm start` | 本番サーバー |
| `npm run typecheck` | 型チェック |

## 構成

Next.js (App Router) + TypeScript + Tailwind CSS v4。教材・進捗・弱点マークは
ブラウザの `localStorage` に保存します（サーバー側に DB はありません。別の端末やブラウザとは共有されません）。

```
src/
  app/
    page.tsx              貼り付け画面 + 使い方 + サンプル教材
    bookshelf/            本棚（レベル絞り込み・削除）
    study/[id]/           学習画面（本文 / 単語帳 / 弱点）
    weakness/             教材をまたいだ弱点レポート
    api/
      analyze/            英文 → 教材（対訳・単語・パート・レベル）
      explain/            弱点マーク → その場の日本語解説
      ocr/                写真 → 英文の書き起こし
      status/             AI 機能が使えるかの問い合わせ
  components/
    study/
      StudyView.tsx       学習画面の親。進捗と弱点マークを束ねる
      useReader.ts        音読プレイヤーの状態機械
      PlayerBar.tsx       速さ・回数・範囲・ループ・声の操作
      SentenceRow.tsx     1文（再生・音読チェック・弱点マーク）
      VocabTab.tsx        単語帳（一覧 / カード）
  lib/
    segment.ts            英文 → 文の分割（略語・小数・イニシャル・会話文に対応）
    material.ts           分割結果と AI 出力を 1 冊の教材に組み立てる
    claude.ts             Claude 呼び出し（解析・解説・OCR）
    offline.ts            API キーが無いときの簡易解析
    samples.ts            サンプル教材 4 本
    storage.ts            localStorage の読み書きと購読
    tts.ts                Web Speech API の読み上げ
```

### 設計上のポイント

- **英文は書き換えない。** 文への分割はサーバー側の TypeScript で行い、モデルには
  「番号つきの英文」を渡して訳とメタ情報だけを返させます。モデルに原文を再出力させないので、
  勝手な言い換えや脱落が起きません。
- **長い本文は分けて訳す。** 25 文ずつのチャンクに分けて並列にリクエストし、
  1 回の出力が長くなりすぎないようにしています。タイトル・パート分割・単語抽出は
  本文全体を見る別リクエストで、翻訳と同時に走ります。
- **音声はブラウザの読み上げ機能**（Web Speech API）を使うので、音声合成の API キーも通信も要りません。
- 構造化出力（`output_config.format` + Zod スキーマ）で JSON を受け取り、
  Claude Opus 5 のサーバーサイドフォールバックを有効にしています。

## 既知の制約

- 教材はブラウザに保存されるため、端末やブラウザをまたいだ同期はできません。
- 読み上げの声質・対応言語はブラウザと OS によって異なります（Chrome / Edge / Safari を推奨）。
- 発音記号は AI が付けたもので、辞書由来ではありません。
- 文末が略語で終わる文（`... at 3 p.m.` など）は、次の文と結合されることがあります。
