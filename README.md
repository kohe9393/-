# 英文法 総復習プリント

高校英文法の主要10単元を復習するためのプリント（A4・全14ページ）を生成するリポジトリです。

## 成果物

`english_grammar_review.pdf` — 問題編10ページ ＋ 解答・解説編4ページ。

各単元は次の構成で、1単元がちょうど1ページに収まります。

| パート | 内容 | 問題数 |
| --- | --- | --- |
| 要点まとめ | その単元で押さえる文法事項を5〜7項目 | — |
| A | 4択の空所補充 | 5問 |
| B | ( ) 内の語を適切な形に直す | 3問 |
| C | 和文英訳 | 2問 |

収録単元：時制／完了形／助動詞／受動態／不定詞／動名詞／分詞・分詞構文／関係詞／仮定法／比較（合計100問）。

## ビルド方法

```bash
pip install reportlab
python3 src/build_pdf.py english_grammar_review.pdf
```

日本語は IPAゴシック（`fonts-japanese-gothic` / `fonts-ipafont-gothic` パッケージ）を
PDFに埋め込みます。フォントが見つからない場合は `src/build_pdf.py` の
`FONT_CANDIDATES` にパスを追加してください。

## ファイル構成

- `src/content.py` — 要点・設問・解答・解説のデータ。内容を直すときはここだけを編集します。
- `src/build_pdf.py` — 組版スクリプト（ページ体裁、見出し、表、記入欄の描画）。
