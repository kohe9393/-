# 河合塾 英文法・語法演習T 復習解説プリント

| ディレクトリ | 中身 |
|---|---|
| `prompts/` | 復習解説プリント 生成プロンプト（汎用テンプレート v3） |
| `materials/` | 講ごとの4資料（問題ページ／解答／サブテキスト／年間フォロー） |
| `output/` | 生成した `第◯講_（単元名）_復習解説プリント_全体版.md` と印刷用PDF |

## 手順

1. `materials/第◯講/` に4資料のPDFを置く。
2. `prompts/復習解説プリント_生成プロンプト_v3.md` の【記入欄】を埋めて渡す。
3. 生成された全体版Markdownを `output/` に置き、A4印刷用PDFに変換する。
