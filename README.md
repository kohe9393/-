# 日本史 一問一答（坂本先生プリント）

スマホのブラウザで使う、日本史の一問一答学習アプリ。難関私大レベル。

**公開URL: https://kohe9393.github.io/-/**
（ホーム画面に追加するとアプリのように使えます。一度開けば圏外でも動きます）

## 構成

- `index.html` … アプリ本体（HTML/CSS/JS を1ファイルに同梱。外部ライブラリ・CDN不使用）
- `sw.js` … オフライン用 Service Worker
- `data/questions.json` … 問題本体（唯一の正データ）
- `data/history.json` / `data/stats.json` … 学習記録のバックアップ兼分析用
- `CLAUDE.md` … Claude が守る運用ルール

## 収録

坂本日本史プリント 全30章（通史24章＋文化史6章）＝ 1583問。
時代・単元・タグ・難易度（1〜3）を付与。

## 機能

- 出題4モード（通常／間違えた問題のみ／範囲指定／弱点タグ）
- 自己採点3ボタン（正解／惜しい／不正解）と簡易SRS（1日→3日→7日、連続正解2回で卒業、月1回抜き打ち）
- 10問ごとに正答率と弱点タグを表示
- オフライン対応、ダークモード固定、片手操作前提

## データの同期

学習中の正データは端末の localStorage。リポジトリ側はバックアップなので、
アプリの「エクスポート」→ チャットに貼る → Claude が更新、の一方向でのみ同期する。
復元は「インポート」ボタン（機種変更・復元用）。
