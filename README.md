# 特選プリント・ジェネレータ

「夏 特選1講」と同じ体裁のプリントを、**別の英文でも**組めるようにしたツールです。
JSON に英文と和訳を入れると、A4 の印刷用 HTML を出力します。

サンプルとして **英語T（長文）第1講**（Human Tide / Paul Morland）を 1 本組んであります。
和訳は配布資料の全訳例を 1 文ずつに割り当てたものです。

- `build/eigo-T-01.html` … 和訳入り（配布・板書用）
- `build/eigo-T-01-blank.html` … 和訳欄を空罫にした演習用

---

## 元プリントの体裁（再現した仕様）

夏特選1のプリントは、**印刷されている部分**だけ見ると次の 4 要素でできています。
手書きの S / V / O / C、矢印、囲みは全部あとから書き込むもので、版面の仕事は
「**書き込む余白を用意すること**」に尽きます。

| 要素 | 仕様 |
|---|---|
| 段落番号 | 左端の枠囲み数字（1, 2, 3 …） |
| 文番号 | 段落内の通し番号「1、2、3、…」を左の柱に |
| 英文 | セリフ体・両端揃え・**全行に下線罫**、行送りは約 3 倍（下の空きに SVOC を書く） |
| 和訳 | 明朝・1 字下げ・英文のすぐ下 |

下線罫は「1 行ごとに引いた罫線」ではなく **英文そのものの下線**です。だから行末で
罫が止まり、文の切れ目が目で分かる。ここが体裁の肝なので同じ作りにしてあります。

---

## 使い方（3 ステップ）

### 1. 英文をテキストで用意する

段落の切れ目は**空行**にします。テキストの打ち込みだけは手作業（またはOCR）です。

```
lessons/eigo-T-02.txt

To get a sense of ... . When in 47 BC ... .

Between 1840 and 1857 ... .
```

設問の下線部には `{{1}}` `{{2}}` と書いておくと、印刷時に `(1)` の小さな番号になります。

### 2. JSON の雛形を作る

```bash
python3 tokusen.py init lessons/eigo-T-02.txt --title "長文T 第2講" --lesson "第 2 講"
```

段落分け・**文分けまで自動**でやります（`47 BC Julius` のような略語では切りません）。
できた `lessons/eigo-T-02.json` の `"ja": ""` に和訳を書き入れてください。

```json
{
  "title": "長文T 第2講",
  "lesson": "第 2 講",
  "source": "出典表記",
  "notes": [{ "word": "matriarch", "gloss": "女家長" }],
  "paragraphs": [
    { "n": 1, "sentences": [{ "en": "To get a sense of ...", "ja": "ここ200年ほどの…" }] }
  ]
}
```

文分けが気に入らないところは JSON を直接いじれば済みます（1 文を 2 つに割る、
長い関係詞節で切る、など）。**自動分割は下書き、最後は手で決める**という前提の作りです。

### 3. 組んで印刷する

```bash
python3 tokusen.py build lessons/eigo-T-02.json                    # → build/eigo-T-02.html
python3 tokusen.py build lessons/eigo-T-02.json --variant blank    # → 和訳空欄の演習用
```

出力した HTML をブラウザで開き、**Ctrl/Cmd + P → 用紙 A4・余白「既定」→ PDF に保存**。
（`@page` で A4 と余白を指定してあるので、余白は「なし」にしないでください。）

---

## 調整

書き込み欄の高さと英文の大きさはコマンドラインから変えられます。

```bash
python3 tokusen.py build lessons/eigo-T-02.json --leading 3.4   # 書き込み欄を広く
python3 tokusen.py build lessons/eigo-T-02.json --leading 2.7 --en-size 10.6pt  # 詰めて枚数を減らす
```

それ以外（フォント、段落番号の枠、和訳の級数など）は `tokusen.py` 冒頭の `CSS` を
直接いじってください。`:root` の変数に主要な値をまとめてあります。

## ファイル

```
tokusen.py              ジェネレータ本体（Python 3 標準ライブラリのみ・依存なし）
lessons/eigo-T-01.txt   英文べた打ち（原稿）
lessons/eigo-T-01.json  英文＋和訳＋語注（組版データ）
build/*.html            出力（ブラウザで開いて印刷）
```
