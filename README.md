# めくる単語帳

自分の単語帳を読み込んで、**スワイプ**と**4択クイズ**で覚える単語アプリです。
まちがえた単語は「なぜ苦手なのか」を分析して、覚えるまでくり返し出題します。

iPhone / Android のホーム画面に追加すると、アプリのように全画面・オフラインで使えます（PWA）。
サーバーやアカウントは不要で、データは端末の中だけに保存されます。

## できること

| 機能 | 内容 |
| --- | --- |
| 単語帳の読み込み | CSV・TSV・テキストファイル、Excel／スプレッドシートからのコピペ、Quizlet・Anki の書き出しに対応。区切り方や見出し行、通し番号、Shift_JIS の CSV も自動で判定します |
| スワイプ学習 | カードをタップでめくり、右へはじくと「覚えた」、左へはじくと「まだ」。キーボードの ← → とスペースでも操作できます |
| 4択クイズ | 「単語→意味」「意味→単語」「ミックス」。選択肢には、前に取り違えた単語やつづりが似た単語（adapt / adopt など）を優先して混ぜます |
| まちがえた単語のくり返し | 学習中にまちがえた単語は数枚あとにもう一度出題し、正解するまでくり返します |
| 苦手分析 | 苦手ランキングと理由（連続でミス・何回もミス・覚えたのに忘れた・○○と混同・つづりが似た語）、取り違えやすい組み合わせ、習熟度、14日間の学習記録 |
| 間隔反復 | 正解するたびに次の復習までの間隔が伸び（翌日 → 3日後 → 1週間後 …）、まちがえると短く戻ります |
| 出題モード | おまかせ／苦手だけ／未学習／ランダム |
| その他 | 発音の読み上げ、ダークモード、バックアップの書き出し・復元、単語帳の CSV 書き出し |

## 読み込める形式の例

どれも「1行に単語と意味（あれば例文・メモ）」です。区切りは自動で判定されます。

```text
apple	りんご                      ← タブ区切り（Excel などからコピペ）
abandon,"捨てる, 見捨てる",He abandoned the plan.   ← CSV（3列目は例文）
take off - 離陸する                  ← ハイフン
apple: りんご                        ← コロン
give up 諦める                       ← スペースだけ（英語と日本語の境目で分けます）
1. ability 能力                      ← 番号付きリスト（番号は外します）
```

1行目が「英単語,意味,例文」のような見出しなら、列の順番も見出しに合わせます。
「単語」「意味」を空行で区切ったまとまりや、1行ずつ交互に書いたリストにも対応しています。

## iPhone で使うには

このアプリはビルド不要の静的ファイルだけでできているので、そのまま公開できます。

1. GitHub のリポジトリで **Settings → Pages** を開き、
   **Source: Deploy from a branch / Branch: `main`・`/ (root)`** を選んで保存
2. 数分後に表示される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を iPhone の Safari で開く
3. 共有ボタン → **ホーム画面に追加**

以後はホーム画面のアイコンから、アプリとして全画面・オフラインで起動できます。

> データは端末の中（ブラウザの保存領域）にあります。機種変更の前などは、設定画面の「バックアップを書き出す」で保存してください。

## 復習のしくみ

- **1回の学習（おまかせ）**：復習の時期が来た単語を「苦手度」と「期限切れの長さ」の順に並べ、そこへ未学習の単語を少し（初期設定 10語）足して出題します。
- **学習中**：まちがえた単語は数枚あと（初期設定 3枚あと）にもう一度出します。3回までくり返しても覚えられなければ、次回に回します。
- **次の復習日**：まちがえると 10分後、正解すると 翌日 → 3日後 → 前回の間隔 ×「覚えやすさ」（最初 2.5）… と伸びます。まちがえるたびに「覚えやすさ」が下がり、その単語は短い間隔で出るようになります。初見で正解した単語は 3日後に回します。
- **苦手度**：正答率・直近5回の結果・前回ミスしたか・覚えたあとに忘れた回数から 0〜1 で計算し、0.35 以上を「苦手」としています（`js/srs.js`）。
- **習熟度**：未学習 → 学習中 → 定着中（間隔 3日以上）→ マスター（間隔 21日以上）。

## 開発

依存パッケージはありません。Node.js 18 以上でテストを実行できます。

```sh
npm test          # 単体テスト（読み込み・復習の計算・出題・保存など）
npm start         # http://localhost:8080 でアプリを起動（Python 3 を使用）
```

ファイルを変更して公開するときは、`sw.js` の `CACHE` の番号（`mekuru-v1`）を上げると、利用者の端末でも新しい版に入れ替わります。
`js/` にファイルを追加したら `sw.js` の `ASSETS` にも追加してください（テストで確認しています）。

```
index.html            画面の土台
css/style.css         デザイン（ライト／ダーク）
js/app.js             画面の切り替え・起動
js/parser.js          単語リストの読み取り（CSV・貼り付け・文字コード判定）
js/srs.js             間隔反復・苦手度・苦手の理由
js/queue.js           1回の学習で出す単語の選び方
js/session.js         学習中の進行（まちがえた単語の再出題）
js/quiz.js            4択の選択肢づくり
js/analytics.js       分析画面の集計
js/store.js           端末への保存・バックアップ
js/swipe.js           カードのスワイプ操作
js/views/             各画面
sw.js                 オフライン対応
tests/                単体テスト
```
