# materials/ — 資料の置き場所

各講ごとに `第◯講/` を作り、**4資料すべて**を置く。1つでも欠けると作業を開始できない
（生成プロンプト「作業開始前の必須チェック」）。

```
materials/
└── 第8講/
    ├── 問題ページ.pdf        # 印刷された問題文・選択肢・整序の語群（原文の再掲元）
    ├── 解答.pdf              # 正解と例文番号の照合用
    ├── サブテキスト.pdf      # 説明の母体（用語・定義・分類・一覧・例文）
    └── 年間フォロー.pdf      # 当該講の該当ページ（切り口と力点）
```

- ファイル名は自由。【記入欄】に実際の名前を書けばよい。
- 年間フォローは**当該講の該当ページ**を指定すること（冊子まるごとでも可だが、ページ範囲を伝える）。
- スキャンでテキスト層がないPDFでも可。その場合はページ画像化して読む。
- 板書（赤字）の写り込みは可。ゼロから分析し、食い違いは指摘する。
